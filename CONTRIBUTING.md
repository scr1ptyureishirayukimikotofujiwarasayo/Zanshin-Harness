# Contributing to Zanshin Harness

Thanks for helping make Zanshin Harness a calmer way to work with coding agents.

## Before opening a pull request

- Keep the interface keyboard accessible and readable over the background art.
- Respect `prefers-reduced-motion` when adding animation.
- Keep interactions local and reversible where possible.
- Run `npm run typecheck`, `npm run lint`, and `npm run build`.
- Keep user-facing copy concise and avoid exposing credentials or private workspace data.

## Pull requests

Describe the user-facing change, include screenshots for visual changes, and call out any follow-up work that is intentionally not included.
